# SYNAP - Sistema de Negocios Autoadministrable del Paraguay

## Propietario

Luis Mario Duré Nuñez "LMTN" - Desarrollador, Programador y Disenador Digital

## Descripcion

SYNAP es un ecosistema de gestion empresarial completo: POS + CRM + ERP + E-commerce con inteligencia artificial integrada. Funciona en cualquier dispositivo con o sin conexion a internet.

## Stack Tecnologico

- Frontend: React 19 + TypeScript + Vite
- Backend: Node.js + Express + TypeScript
- Base de Datos: PostgreSQL 16 + Redis
- Tiempo Real: Socket.io + GraphQL
- Movil: React Native
- Escritorio: Electron
- IA: TensorFlow.js + OpenAI API
- Offline: SQLite + WatermelonDB
